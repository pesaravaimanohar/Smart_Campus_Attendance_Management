# Smart Attendance Management System

A production-ready Student Attendance System using Spring Boot 3, React + Vite, JWT Authentication, and Geo-fencing/QR/Face Verification logic.

## 🚀 Features

- **Role-Based Access Control**: Student, Faculty, Admin.
- **Secure Authentication**: JWT + Password Hashing.
- **Dynamic QR Attendance**: Rotating QR codes generated by Faculty.
- **Geo-Fencing**: Validates student location against session location.
- **Face Verification**: Captures selfie during attendance (stored path).
- **Excel Upload**: Bulk student registration.

## 🛠 Tech Stack

- **Backend**: Java 17, Spring Boot, Spring Security, JPA, MySQL.
- **Frontend**: React, Vite, Material UI, Axios.
- **Database**: MySQL.

## 📋 Prerequisites

1. **Java 17** Installed.
2. **Node.js** (v16+) & **npm** Installed.
3. **MySQL Server** running on localhost:3306.
   - Create database: `smart_attendance` (optional, app will try to create).
   - Copy `.env.example` values into your environment or IDE run configuration before starting the backend.

```bash

mvn spring-boot:run
```

## 🧪 Testing the Flow

1. **Login as Admin**: Upload Students via Excel or use API.
2. **Login as Faculty** (You may need to manually add one to DB or via Admin API once built completely).
3. **Start Session**: Faculty selects class -> Generate QR.
4. **Login as Student**: Mobile view -> Scan QR -> Capture Face -> Submit.
